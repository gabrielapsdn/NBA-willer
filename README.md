# 🌸🏀 NBA Astros Gallery - Rose Gold Edition

Uma aplicação web imersiva, moderna e responsiva desenvolvida em **React 19** e **Vite**, projetada para exibir os maiores astros da NBA com uma identidade visual sofisticada, estilizada e personalizada. O projeto adota arquitetura de componentes modulares e utiliza o hook **`useEffect`** para o carregamento dos dados simulados.

## 🚀 Recursos e Funcionalidades

### 1. Barra Superior (*Top Navbar*)
- Destaque com o ícone **🌸 Gabriela do Nascimento • Turma 3B**.
- Alternador de 3 modos de visualização (**🃏 Cards 3D**, **🏟️ Arena Panorâmica** e **📊 Tabela Técnica**).
- Contador dinâmico de favoritos (`❤️ Favoritos`).

### 2. Palco 3D do Astro em Destaque (*Arena Spotlight*)
- Seção no topo com busca instantânea e filtros por conferência.
- Card de destaque ampliado com halo luminoso em tons de rosa, estatísticas médias (**PPG**, **RPG**, **APG**), curiosidade exclusiva e botões de navegação rápida.
- Ao clicar em qualquer card da galeria, o astro é automaticamente focado no palco central!

### 3. Cards em Estilo Colecionável (*Card.jsx*)
- Camisa estilizada com o número do atleta e sigla do time.
- Halo de luz suave e efeito hover 3D (elevação suave e sombra dinâmica).
- Botão interativo para favoritar com animação de pulso.
- Trinca de métricas e faixa de conquistas.

### 4. Rodapé Personalizado
- Assinatura oficial com o nome de **Gabriela do Nascimento**, identificação da **Turma 3B** e tags das tecnologias utilizadas (**React 19**, **Vite**, **useEffect**, etc.).

## 🛠️ Como Executar o Projeto

1. Abra o terminal na pasta do projeto:
   ```bash
   npm run dev
   ```
2. Acesse a aplicação no seu navegador:
   ```text
   http://localhost:5173/
   ```

3. Para gerar o build de produção:
   ```bash
   npm run build
   ```
